# Dataset

What the dataset is, how it was made, and its limits. Filled in at steps A2 and A5. Per-split
counts go in `stats.md` at step A6.

In short (from `MASTER_PLAN.md` section 5): 3,000 anonymised founder profiles generated with
Adaption, grounded in real founders where possible, each labelled with the company's outcome band
and years to outcome. Because the data is generated, results describe this dataset only, not
real-world accuracy.
